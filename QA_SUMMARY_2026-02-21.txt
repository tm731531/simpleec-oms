⚠️ 發現的問題與建議

【高優先級 - 立即修復】

❌ 問題 #1: REST API 服務故障 (HTTP 500)
   影響: 後端數據同步、實時統計更新
   根因: PostgreSQL 連接失敗或應用啟動失敗
   方案: 檢查DB狀態 → 驗證應用日誌 → 重啟API容器
   時間: 0.5-1 小時

❌ 問題 #2: PostgreSQL 數據庫不可訪問
   影響: 無法驗證真實數據存儲
   狀態: 192.168.0.48:5433 連接失敗
   方案: 檢查容器狀態 → 驗證網絡連接 → 重啟DB

❌ 問題 #3: 貨幣符號不統一
   現象: merchant-portal.html 用 ¥, oms-dashboard 用 $
   建議: 全局統一為 ¥ (適合台灣/中國市場)

【中優先級 - 本周修復】

⚠️ 問題 #4: Mock 數據不同步
   現象: merchant-portal 2個產品, oms-dashboard 4個產品
   建議: 建立共用 mock-data.js, 所有頁面引用同一源

⚠️ 問題 #5: 時間戳格式不標準
   現象: 使用 2026-02-20 10:30, 應為 ISO-8601
   建議: 統一格式並實現本地化顯示轉換

⚠️ 問題 #6: 缺少加載狀態指示器
   現象: 沒有 Loading spinner、進度提示或錯誤提示
   建議: 添加 skeleton screens + error toast + 重試機制
