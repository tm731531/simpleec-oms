⚡ 快速重啟單個服務（推薦用於開發）

修改 Channel Job 代碼 → 快速重啟：
  $ ./quick-redeploy.sh simpleec-channel-job      # 30-40 秒
  $ ./quick-redeploy.sh simpleec-channel-shopee-fast
  $ ./quick-redeploy.sh simpleec-channel-momo-slow

修改 API 代碼 → 快速重啟：
  $ ./quick-redeploy.sh simpleec-api              # 30-40 秒

修改 Scheduler/Order/Backend Job → 快速重啟：
  $ ./quick-redeploy.sh simpleec-scheduler-job
  $ ./quick-redeploy.sh simpleec-order-job
  $ ./quick-redeploy.sh simpleec-backend-job

⚡⚡ 一次重啟多個服務（連帶修改時使用）

修改 Channel Job 和 Order Job：
  $ ./quick-redeploy.sh simpleec-channel-job simpleec-order-job    # 1-2 分鐘

修改 API 和前端應用：
  $ ./quick-redeploy.sh simpleec-api simpleec-user-app             # 1-2 分鐘

修改多個 Channel Jobs（不同平台）：
  $ ./quick-redeploy.sh simpleec-channel-momo-fast simpleec-channel-shopee-fast

修改核心邏輯涉及多個服務：
  $ ./quick-redeploy.sh simpleec-channel-job simpleec-order-job simpleec-backend-job

🔧 完整開發工作流

  1. 修改代碼（編輯 Java 文件）

  2. 本地編譯：
     $ ./gradlew clean build -x test

  3. 快速重啟（只需 30-60 秒！）：
     $ ./quick-redeploy.sh simpleec-channel-job

  4. 查看日誌：
     $ docker logs simpleec-channel-job -f

  5. 測試驗證（API 測試、手動檢查等）

  6. 重複 1-5 快速迭代

❓ 常見問題

Q: 腳本找不到 docker-compose.yml？
A: 確保在 /home/tom/ONEEC/simpleec-oms 目錄執行

Q: Docker 命令失敗？
A: 檢查 docker daemon 是否運行：docker ps

Q: 如何只重建而不啟動？
A: docker compose build --no-cache <service>

Q: 如何查看容器日誌？
A: docker logs <container-name> -f   # -f 表示 follow（持續顯示）

Q: 如何查看執行中的容器？
A: docker ps | grep simpleec
