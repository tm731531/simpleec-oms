┌─────────────────────────────────────────────────────────────────────────────────────────┐
│ 🔄 数据流关键要点                                                                      │
├─────────────────────────────────────────────────────────────────────────────────────────┤
│                                                                                         │
│  ✅ Mode A（直接模式）                                                                  │
│     └─ Shopify: 列表 API 已含完整信息 → 直接组织 OMS → ORDER_UPSERT                   │
│                                                                                         │
│  ✅ Mode B（列表+详情模式）— 统一 {platform}.slow topic                           │
│     ├─ Shopee: 列表 API 缺商品/物流 → 逐单获取详情 → 组织 OMS → ORDER_UPSERT         │
│     └─ Cyberbiz ✨: 列表需两次 API (created+updated) → 逐单详情 → OMS → UPSERT      │
│     • FETCH_ORDERS 和 FETCH_ORDER_DETAIL 流经同一个 {platform}.slow topic           │
│     • ChannelJobConsumer 根据 taskType 路由消息到不同处理器                          │
│                                                                                         │
│  🔐 去重机制（两层）                                                                    │
│     1️⃣ 内存层: 计算 orderHash = SHA256(orderData)                                      │
│     2️⃣ Redis层: 存储 order:hash:{merchantId}:{channelId}:{orderId}                     │
│     3️⃣ DB层: 检查订单是否存在，避免重复更新                                           │
│                                                                                         │
│  ⏰ 时间驱动                                                                            │
│     └─ HeartbeatJob → SchedulerConsumer → FETCH_ORDERS 每 5 分钟                     │
│                                                                                         │
│  🏪 通路隔离                                                                            │
│     └─ 每个平台独立 topic: {platform}.slow (统一处理 FETCH_ORDERS 和 FETCH_ORDER_DETAIL) │
│     └─ 每个通路独立消费者实例                                                          │
│     └─ 支持多商户、多店铺隔离                                                          │
│                                                                                         │
