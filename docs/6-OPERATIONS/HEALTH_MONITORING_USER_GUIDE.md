# 健康監控系統使用指南

## 📱 快速開始

### 1️⃣ 訪問健康監控儀表板

1. 登錄 SimpleEC OMS 用戶應用
2. 在左側菜單中點擊 **「健康監控」**
3. 系統將顯示健康監控儀表板

**URL**: `http://localhost:8089/health`

---

## 📊 儀表板介紹

### 區域一: 整體健康摘要

顯示系統整體健康狀況的快照。

**指標說明**:
| 指標 | 說明 |
|------|------|
| 總檢查數 | 系統自啟動以來進行的所有健康檢查總數 |
| 最近檢查 | 最近記錄的檢查次數(通常為100次) |
| 健康 | 最近檢查中狀態正常的數量 |
| 不健康 | 最近檢查中出現問題的數量 |
| 健康百分比 | 健康檢查占總檢查的百分比 |

**示例解釋**:
```
總檢查數: 5000        (5000次健康檢查)
最近檢查: 100         (樣本為最近100次)
健康: 95              (95次正常)
不健康: 5             (5次出現問題)
健康百分比: 95.0%    (優秀狀態)
```

---

### 區域二: 通路健康狀態查詢

**功能**: 查詢特定商家通路的健康狀況

#### 使用步驟:

1. **輸入通路ID**
   - 在搜尋框中輸入通路ID
   - 例如: `channel-001`, `shopee-merchant-123`

2. **點擊「搜尋」按鈕**
   - 系統將立即查詢該通路的健康狀態
   - 顯示最新的檢查結果

3. **查看狀態詳情**
   - **狀態**: 綠色表示「正常」，紅色表示「異常」
   - **HTTP狀態碼**: 200 = 成功，401 = 令牌失效等
   - **錯誤信息**: 若有問題，將顯示具體錯誤描述

4. **查看檢查歷史**
   - 表格顯示該通路最近的檢查記錄
   - 時間戳: 檢查進行的時間
   - 狀態: 該次檢查的結果
   - HTTP代碼: 返回的HTTP狀態碼
   - 錯誤信息: 若有異常顯示錯誤內容

#### 常見搜尋場景:

**場景1: 商家反映訂單同步有問題**
1. 搜尋商家的通路ID
2. 查看最近的狀態 → 如果是紅色，找出HTTP狀態碼
3. 根據狀態碼判斷原因(見下方狀態碼對照表)
4. 採取相應的解決措施

**場景2: 定期監控通路狀態**
1. 每天定時查看一次
2. 查看「不健康」計數是否有增加
3. 如果有異常，檢查錯誤日誌

## 🔍 狀態碼對照表與解決方案

### ✅ 正常狀態 (200-299)

| HTTP碼 | 含義 | 說明 |
|------|------|------|
| 200 | OK | API正常運作 |
| 201 | Created | 資源成功建立 |

**應對方式**: 無需操作，一切正常

---

### ⚠️ 需要關注 (300-399)

| HTTP碼 | 含義 | 說明 | 建議操作 |
|------|------|------|---------|
| 301 | Moved Permanently | API已永久遷移 | 聯繫平台確認新端點 |
| 302 | Found (重定向) | 請求被重定向 | 檢查配置文件中的API端點 |
| 307 | Temporary Redirect | 臨時重定向 | 通常自動處理，留意日誌 |

---

### 🔴 常見錯誤 (400-499)

#### 401 Unauthorized - 令牌失效

**含義**: 提供的API令牌無效或已過期

**常見原因**:
- 令牌已過期(通常是90天)
- 令牌被平台撤銷
- 令牌格式不正確
- 商家賬戶被禁用

**解決方案**:
1. 登入SimpleEC OMS管理後台
2. 進入「平台管理」或「商家管理」
3. 找到對應通路，檢查令牌
4. 通常需要重新授權:
   - 去該平台的開發者中心
   - 重新生成或驗證API令牌
   - 複製新令牌到OMS系統
5. 刷新後狀態應變為綠色

**預防措施**:
- 設置提醒: 令牌有效期快要結束時
- 每月檢查一次令牌狀態
- 建立文檔記錄每個商家的令牌更新日期

---

#### 403 Forbidden - 權限不足

**含義**: 令牌有效，但沒有調用該API的權限

**常見原因**:
- 令牌綁定的賬戶權限不足
- 商家未订阅所需功能
- API权限配置错误
- 商家已被封禁

**解決方案**:
1. 檢查商家賬戶狀態
   - 登入平台官方商家後台
   - 確認賬戶是否被禁用或凍結
2. 檢查API權限
   - 確認令牌綁定的應用已授予必要權限
   - 通常需要在平台開發者中心配置
3. 檢查訂閱狀態
   - 確認商家已訂購該功能
   - 可能需要升級商家方案
4. 聯繫平台支持
   - 提供商家ID和令牌
   - 請求平台確認權限配置

**預防措施**:
- 新增商家時驗證所有必要權限
- 建立權限檢查清單

---

#### 404 Not Found - API端點不存在

**含義**: 請求的API端點不存在或已停用

**常見原因**:
- API端點已被平台廢棄
- 平台版本升級，端點改變
- 配置中的API地址錯誤
- 拼寫錯誤

**解決方案**:
1. 檢查OMS系統中的API端點配置
2. 參考該平台的最新API文檔
3. 與平台確認是否還支持該端點
4. 如果端點已改變，更新OMS配置
5. 某些平台可能需要更新SDK版本

---

#### 429 Too Many Requests - 速率限制

**含義**: 短時間內發送了太多請求

**常見原因**:
- 檢查頻率過高(每5分鐘可能還是太快)
- 平台施加了每秒/分鐘請求限制
- 多個系統同時請求該平台

**解決方案**:
1. **降低檢查頻率**
   - 修改調度器: 改為每10分鐘檢查一次
   - 聯繫管理員修改配置
2. **檢查是否有其他系統也在調用**
   - 確認只有OMS在做健康檢查
3. **申請API限額提升**
   - 在平台開發者中心申請更高限額
   - 提供使用說明

**臨時措施**:
- 系統會自動等待並重試
- 狀態會短時間內自動恢復

---

### 🔴 嚴重錯誤 (500-599)

#### 500 Internal Server Error - 平台服務錯誤

**含義**: 平台自身遇到異常

**常見原因**:
- 平台服務器故障
- 平台正在進行維護
- 平台資料庫出問題
- 平台代碼有缺陷(罕見)

**解決方案**:
1. **查看時間** - 記錄錯誤時間
2. **檢查平台狀態頁** - 訪問平台官方狀態頁確認是否有異常
3. **等待平台恢復** - 通常15-60分鐘會恢復
4. **聯繫平台支持** - 如果持續超過2小時
5. **臨時備案** - 通知商家可能有延遲

**預防措施**:
- 對於重要商家，可建立備用方案
- 保留平台支持聯繫方式
- 建立故障升級流程

---

#### 503 Service Unavailable - 平台不可用

**含義**: 平台當前無法提供服務

**常見原因**:
- 平台正在進行定期維護
- 平台遭遇DDoS攻擊
- 平台資源耗盡
- 平台網絡故障

**解決方案**:
1. **檢查平台維護公告**
   - 通常有提前通知
   - 查看平台官方博客或狀態頁
2. **等待** - 大多數情況會自動恢復
3. **確認網路** - 確認OMS的網路連接正常
4. **聯繫支持** - 如果持續時間過長

**預防措施**:
- 訂閱平台的維護日程表
3. 提前通知受影響的商家

## 🔧 常見問題

### Q: 為什麼顯示「Channel not found」?

**A**: 可能是:
1. 輸入的通路ID不正確 - 確認ID完全匹配
2. 通路已被刪除 - 檢查後台管理界面
3. 通路未啟用 - 通路的 `enableSync` 字段可能是false

**解決**: 確認通路ID，檢查通路配置

---

### Q: 某個平台總是顯示紅色，我該怎麼辦?

**A**: 按以下步驟排查:
1. 檢查是否是維護時間 → 查看平台官方狀態頁
2. 查看HTTP狀態碼 → 根據上面的對照表處理
3. 檢查令牌是否有效 → 聯繫管理員驗證
4. 檢查網路連接 → 確認OMS可以連接外網
5. 聯繫技術支持 → 如果仍無法解決

---

### Q: 健康百分比忽高忽低是什麼原因?

**A**: 可能是:
1. **高負載時段** - 平台在高峰期回應慢，容易超時
2. **網路不穩定** - 檢查OMS到平台的網路質量
3. **檢查頻率太高** - 可能觸發速率限制
4. **令牌接近過期** - 平台可能在這段時間內驗證更嚴格

**建議**:
- 查看具體發生時間，是否有規律
- 調整檢查超時時間
- 確保令牌有充足的有效期

---

### Q: 怎樣導出健康檢查報告?

**A**: 當前版本支持:
1. **直接截圖** - 對儀表板進行截圖
2. **查看歷史數據** - 點擊「View History」可看到表格，可複製
3. **API查詢** - 技術人員可以直接調用REST API獲取數據

未來版本將支持:
- 導出為PDF報告
- 導出為Excel表格
- 自動生成週報/月報
